# Project 1: Prompting & RAG Foundations

## Required Capabilities

The final submission must demonstrate:

- ingestion of a small document corpus
- chunking and retrieval
- grounded generation with document and section citations
- clear refusal when retrieved evidence does not support an answer
- three tone transformations
- few-shot structured output for tone transformation
- CLI or UI access
- chunking and prompt experiments
- at least 20 evaluation questions
- retrieval, grounded, failure, tone, and model-comparison evaluation

## Acceptance Criteria

The final repository reports PASS/PARTIAL status for all eight supervisor criteria in `README.md` and `docs/FINAL_REPORT.md`.

## Evidence Policy

Saved Final v2 outputs, labels, metrics, prompts, and selected index bytes are treated as frozen evidence. Validation must not make external model calls.
